## 2、结构解析

```js
HTTP/1.1：http版本号
200：响应状态码
ok：响应状态的描述
```

## 3、响应状态码

| 状态码 | 含义           | 状态描述              |
| ------ | -------------- | --------------------- |
| 200    | 请求成功       | Ok                    |
| 403    | 禁止请求       | Forbidden             |
| 404    | 找不到资源     | Not Found             |
| 500    | 服务器内部错误 | Internal Server Error |

## 4、响应状态码表示

| 状态码 | 含义           |
| ------ | -------------- |
| 1xx    | 信息响应       |
| 2xx    | 成功响应       |
| 3xx    | 重定向消息     |
| 4xx    | 客户端错误响应 |
| 5xx    | 服务端响应错误 |
