# 一、响应头和响应体

## 一、响应头

解析：响应头是记录与`服务器`相关的一些内容

![image-20241026212120881](C:\Users\谭磊\AppData\Roaming\Typora\typora-user-images\image-20241026212120881.png)

```
1、serve：记录了服务器使用的一些技术
2、Data：记录了服务器响应的一个时间
3、contente-type：记录了与响应体的内容格式
4、content-length：记录了响应体的内容长度，单位是字节
```

## 二、响应体

解析：响应体的内容格式非常灵活，常见的响应体其实就是`前端`，如下：

1、html

2、css

3、javascript

4、图片

5、视频

6、JSON
