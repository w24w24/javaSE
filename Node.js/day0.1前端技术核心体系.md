# 二、为什么需要学习Node.js？

需求：我们写了一个网页，有哪些办法可以让其它用户可以访问到我们写的网页？

选择1：我们将写的html、css、js文件分别`单独`发送给想要访问的用户【有10个人可以发送，有10w个人呢？】

选择2：通过Node.js编写服务器，让用户自己访问这些html、css、js文件【可行】

#### <span style="color:red">注意：Vue、React、Angular都需要使用Node.js，所以学习Node.js非常有必要</span>



# 三、Node.js是什么？

官方：Node.js is an open-source,cross-platform javascript runtime environment.

翻译：Node.js是一个开源的，跨平台的javascript运行环境

通俗：Node.js就是一款应用程序，是一款软件，它可以运行javascript
