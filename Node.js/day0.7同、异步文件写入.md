# 一、_fs模块：同步和异步

解析：在学习同步和异步的时候，需要先了解线程和进程

1、进程：就是一个程序运行的进度和概况

2、线程：就是一个进程中的小事件、小分支

3、同步：就是一起做

4、异步：就是各自做

# 二、同步和异步示例

示例：

```
我和哥哥去打篮球【去打篮球就是进程】

但是中途哥哥去上厕所了【上厕所就是线程】

我有两个选择，一个是等哥哥回来一起去篮球场【等哥哥回来一起去篮球场，就是同步】

第二个选择是我直接去篮球场，哥哥上完厕所自己来篮球场【我先去篮球场，哥哥后面自己来篮球场，这个就是异步】
```

# 三、异步代码

异步代码语法：fs.writeFile(file, data, options, callback)，`【file是写入的文件名字、data是写入的内容、options是选项设置、callback是写入成功或者失败的回调函数】`

特点：

1、异步代码是不会等待结果回来的，会直接往下执行

2、异步代码不会影响主进程，会自己新开一个线程来处理，所以需要一个回调函数来处理数据

```js
fs.writeFile('./座右铭.txt','人生自古谁无死，留取丹心照汗青', err =>{
  if(err) {
    console.log('写入失败...');
    return;
  }
  console.log('写入成功！')
})

console.log(1 + 1); // 这里会先执行
```

# 四、同步代码

同步代码语法：fs.writeFileSync(file, data, options)，`【file是写入的文件名字、data是写入的内容、options是选项设置】`

特点：

1、同步代码需要等待结果返回之后才会执行下一步

2、同步代码是没有回调函数的，因为同步代码是按照顺序执行的，直接返回结果，所以不需要回调函数

```js
// 异步代码
fs.writeFileSync('./人生格言.txt', 'test');
console.log( 2 + 2); // 依次执行
```
