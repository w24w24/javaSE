# 一、IP的分类

IP：是所有上网设备的网络设备标识

IP的组成：IP是又32bit的数字组成的，但是因为数字太多，在开发中使用的时候不方便，于是将这32bit的数字分为4组，每组就是8bit，然后再将每一组数字转换为二进制，然后使用逗号进行隔开，如下：192.168.1.0

## 一、共享IP

概念：就是在一个区域内的设备来共享一个IP，比如：在家庭中，我们的手机、电脑、iPad链接路由器网络，这个时候，这些设备就是在共享路由器的IP

共享IP分类：区域共享、家庭共享

## 二、本地回环IP

概念：这个IP地址永远是指向本机的，即现在使用的设备的IP地址

IP地址：在`127.0.0.1 ~ 127.255.255.254`之间的IP地址，都是指向当前本机的
